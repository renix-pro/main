## 4. Fixes applied (branch `local/audit`)

| Fix | Change | Verified by |
|---|---|---|
| R1 | `GET /objects/*` now requires `requireAuth` and an ownership check: project-scoped paths → project owner/member; legacy paths → a document / source document / pending upload / hero image owned by the user must reference the exact path. Foreign or unknown paths answer 404. | unauth → 401; owner → 200 `application/pdf`; other user → 404; seeded doc of another owner → 404 |
| R2 | `DELETE /api/projects/:id` no longer uses `requireWriteAccess`; it allows `active` and `closed`, 404 on `deleted`. | close → write 403 → delete 200 |
